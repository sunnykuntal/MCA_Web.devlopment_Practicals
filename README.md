# MCA Web Technology and Application Design Practicals

A complete collection of practical assignments developed as part of the
MCA Web Technology and Application Design coursework.

This repository contains six practical implementations covering HTML5,
CSS3, responsive web design, forms, validation, CSS layouts, UI styling,
and Bootstrap-based dashboard development.

---

## About the Project

This repository contains the practical work completed for the
**MCA Web Technology and Application Design** subject.

The practicals are designed to demonstrate the use of modern web
development concepts including:

- Semantic HTML5
- HTML Forms and Validation
- CSS3 Styling
- CSS Flexbox
- CSS Grid
- Responsive Web Design
- Media Queries
- CSS Transitions and Transforms
- Product Catalogue Design
- E-commerce Product Listing
- Bootstrap Grid System
- Bootstrap Components
- Responsive Tables
- Accessibility-friendly image alt text
- Metadata and SEO basics

All practicals are developed using clean HTML and CSS, with Bootstrap
used where required by the practical specification.
